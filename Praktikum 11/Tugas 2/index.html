❓ FAQ Accordion

Apa itu tag semantic HTML?
Tag semantic adalah elemen HTML yang memiliki makna jelas, seperti <header>, <nav>, <article>, dan <footer>. Penggunaan tag semantic membantu mesin pencari dan pembaca layar memahami truktur halaman.
Apa perbedaan <div> dan <span>
<div> adalah elemen block yang memakan satu baris penuh, biasanya digunakan untuk mengelompokkan section besar. <span> adalah elemen inline yang digunakan untuk menandai sebagian kecil teks di dalam paragraf.
Apa itu CSS specificy
Specificity adalah sistem yang digunakan browser untuk menentukan aturan CSS mana yang diterapkan ketika ada konflik. Semakin spesifik selectornya (ID > class > tag), semakin tinggi prioritasnya.
Apa perbedaan display flex dan grid?
Flexbox dirancang untuk layout satu dimensi (baris atau kolom). CSS Grid dirancang untuk layout dua dimensi (baris DAN kolom sekaligus). Keduanya bisa dipakai bersamaan.
Apa itu event bubbling?
Event bubbling adalah perilaku di mana event yang terjadi pada elemen anak akan menyebar ke elemen parentnya. Misalnya klik pada <button> di dalam <div> juga akan memicu event pada <div> tersebut.
Apa perbedaan == dan === di JavaScript?
== membandingkan nilai saja dan melakukan type coercion (konversi tipe otomatis), sehingga '5' == 5 bernilai true. === membandingkan nilai DAN tipe data, sehingga '5' === 5 bernilai false.
